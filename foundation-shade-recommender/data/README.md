# Data

This folder intentionally excludes downloaded datasets.

The notebooks load:

- `shades.csv` from The Pudding's public makeup-shades project.
- FairFace validation images through the Hugging Face `datasets` package.
- Luxxify product and review CSV files for the optional text-classification
  experiment.

Generated tables can be written to `outputs/tables/`. Do not commit selfies,
private images, or other personal data.
